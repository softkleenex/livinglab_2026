# MDGA - 사용자 플로우 및 UI/UX 시나리오 (User Flow)

본 문서는 MDGA 시스템의 핵심 사용자(농민, B2B 클라이언트, 관리자)별 시나리오를 정의합니다.

## 1. 농민/데이터 생산자 (Data Provider) 플로우

농민은 자신의 영농 데이터를 쉽게 업로드하고, 내 농장의 현황을 대시보드로 확인합니다.

1.  **로그인/회원가입:** 휴대전화 번호 또는 카카오/네이버 소셜 로그인.
2.  **농장 등록:** 지도 상에서 내 농장의 위치(폴리곤 또는 핀)를 지정하고 작물 및 면적 입력.
3.  **데이터 입력 (Data Ingestion):**
    *   **"오늘의 일지 작성"** 버튼 클릭.
    *   스마트폰으로 찍은 작물 사진 업로드 + "오늘 온실 온도가 30도까지 올랐고, 딸기에 흰가루병이 약간 보임" 텍스트 입력.
    *   -> **[AI 파싱 진행 중...]** UI 표시.
    *   -> 파싱된 결과(온도 30도, 흰가루병 True, 작물: 딸기) 확인 후 **[저장]** 클릭.
4.  **내 농장 대시보드:** 주간 온도 변화, AI가 예측한 병해충 위험도 알림 확인.

## 2. B2B 클라이언트 / 연구기관 (Data Consumer) 플로우

데이터 구매자는 Twin Map을 통해 광범위한 지역의 작황을 시뮬레이션하고 데이터를 구매합니다.

1.  **로그인:** 기업 계정 로그인.
2.  **Twin Map 분석 (Visualization):**
    *   전국 지도가 표시되고, 각 지역별 작물 재배 밀도와 현재 THI 지수가 히트맵으로 렌더링됨.
    *   필터 적용: "작물: 딸기", "지역: 경상남도", "기간: 2026년 5월".
3.  **기후 시뮬레이션 실행:**
    *   "기후 시나리오: 폭염 (+3도 상승)" 옵션 선택 후 **[시뮬레이션 실행]** 클릭.
    *   히트맵의 색상이 붉은색(위험)으로 변경되며, 예상 수확량 감소폭이 지역별로 표시됨.
4.  **합성 데이터 구매 (Marketplace):**
    *   시뮬레이션 결과를 확인한 후, 우측 패널의 **[이 데이터셋 패키지 구매하기]** 클릭.
    *   결제 완료 후 **[My API Keys]** 화면으로 이동하여 데이터 연동용 API Key 발급.

## 3. 관리자 (System Admin) 플로우

1.  **모니터링 대시보드:** 일일 업로드된 데이터 건수, Gemini API 호출 비용 및 오류율 확인.
2.  **기상청 스케줄러 관리:** 데이터 동기화 실패 시 수동 트리거 버튼 제공.
3.  **마켓플레이스 승인:** 신규 생성된 합성 데이터 패키지의 적합성을 검토하고 마켓에 활성화(Publish) 처리.
