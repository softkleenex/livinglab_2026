# MDGA - 사용자 플로우 및 UI/UX 시나리오 (User Flow)

본 문서는 MDGA 시스템의 핵심 사용자(양돈 농가, 스마트팜 농가, B2B 클라이언트, 관리자)별 시나리오를 정의합니다. 최근 인터뷰 피드백을 반영하여 농업 AX(Agricultural AX)에 특화된 플로우로 재구성되었습니다.

## 1. 양돈 농가 플로우 (Livestock/Pig Farmer)

양돈 농가는 차단 방역을 최우선으로 하며, 번거로운 행정 서류 작업을 최소화하고 질병 징후를 조기에 발견하는 데 목적이 있습니다. (장비 공유 기능은 방역 문제로 배제됨)

1.  **로그인/회원가입:** 휴대전화 번호 또는 카카오/네이버 소셜 로그인.
2.  **HACCP & 백신 일지 자동화 (Data Ingestion):**
    *   **[현장 일지 촬영]** 또는 **[간편 음성 입력]** 버튼 클릭.
    *   스마트폰으로 수기 교배/백신 일지를 촬영하거나, "오늘 A동 3번 돼지 구제역 백신 접종 완료"라고 음성 입력.
    *   -> **[AI 파싱 진행 중...]** UI 표시.
    *   -> 정부 표준(JSON) 데이터로 자동 변환된 결과 확인 후 **[저장]** 클릭 (이중 입력 방지).
3.  **방역 및 환경 위험 지도 모니터링 (Twin Map):**
    *   주변 지역의 아프리카돼지열병(ASF) 발생 현황, 국지성 폭염 경보, 환기 지수 경계 등을 실시간 지도로 확인.
4.  **폐사 위험 골든타임 알림:**
    *   AI가 사료 섭취량 및 일평균 음수량의 급감 등 이상 징후를 감지하면 스마트폰으로 강력한 경고 알림(심각/고위험 등) 전송.

## 2. 스마트팜 농가 플로우 (Smart Farm / Crop Producer)

스마트팜 농가는 분산된 유통/판매 데이터를 통합하고, 이를 바탕으로 최적의 재배량을 추천받아 수익을 극대화하는 데 목적이 있습니다.

1.  **로그인:** 농가 계정 로그인.
2.  **생육 환경 모니터링:** 
    *   온/습도 등 작물 생육 환경 데이터를 대시보드에서 확인.
3.  **통합 매출 및 출고 대시보드 확인:**
    *   다양한 쇼핑몰(스마트스토어, 쿠팡 등)에서 발생한 이번 달 총 매출과 출고 완료 수량(박스)을 한 화면에서 통합 조회.
4.  **AI 재배량 추천 (Insight):**
    *   통합된 연평균 판매 데이터와 기후 시나리오를 바탕으로 "최근 3개월 판매량 증가 추세. 다음 달 재배량 15% 상향 권장"과 같은 AI 인사이트 확인 후 영농 계획 수립.

## 3. B2B 클라이언트 / 연구기관 (Data Consumer) 플로우

데이터 구매자는 농가에서 수집된 비식별화 합성 데이터를 시뮬레이션하고 구매합니다.

1.  **로그인:** 기업/기관 계정 로그인.
2.  **데이터 마켓플레이스 탐색:**
    *   'AI-Ready Vision 데이터(자율주행 트랙터/비전 학습용)', '합성 작황/기후 데이터' 등 카탈로그 확인.
3.  **데이터 내보내기 및 연동:**
    *   **[Snowflake 연동 (CSV)]** 또는 **[AI Hub 납품 (JSONL)]** 버튼을 통해 구매한 합성 데이터를 즉시 추출 및 파이프라인 연동.

## 4. 관리자 (System Admin) 플로우

1.  **모니터링 대시보드:** 일일 업로드된 데이터 건수, Gemini API 호출 비용 및 오류율 확인.
2.  **마켓플레이스 승인:** 신규 생성된 합성 데이터 패키지의 적합성을 검토하고 마켓에 활성화(Publish) 처리.
